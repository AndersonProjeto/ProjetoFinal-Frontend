# ProjetoFinal-Frontend

O frontend do ACADIA é responsável pela interface do usuário e pela experiência de uso do sistema fitness inteligente. Ele consome a API REST do backend e permite que o usuário gerencie seus treinos, exercícios, evolução corporal e interações com Inteligência Artificial de forma visual e intuitiva.

O frontend é responsável por:

- Interface do usuário
- Navegação entre páginas
- Consumo da API backend
- Exibição de dados e dashboards
- Interação com a IA
- Personalização do perfil do usuário

### Resumo 

O ACADIA Frontend é a camada responsável pela interface e experiência do usuário de um sistema fitness inteligente. Desenvolvido inteiramente em React, o frontend consome a API REST do backend para permitir o gerenciamento de treinos, exercícios, evolução corporal, perfil do usuário e interações com Inteligência Artificial.

A aplicação oferece dashboards visuais, gráficos de evolução, personalização de perfil com avatares dinâmicos, histórico de interações com a IA e uma navegação intuitiva e responsiva, adaptada para diferentes dispositivos.

O projeto utiliza uma arquitetura baseada em componentes, com organização por páginas, componentes reutilizáveis e serviços para comunicação com o backend, garantindo escalabilidade, manutenibilidade e boa experiência de uso.
